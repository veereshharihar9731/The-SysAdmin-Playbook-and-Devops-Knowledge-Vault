Jenkins
Jenkins is an open-source automation server used to automate software building, testing and deployment.

1. Developer pushes code to GitHub.
2. Jenkins detects the changes.
3. Jenkins downloads the code.
4. Jenkins builds the application.
5. Jenkins runs tests.
6. Jenkins deploys the application.
This process is called CI/CD (Continuous Integration and Continuous Delivery/Deployment).

What is a Jenkins job?
A Jenkins job is a configured task that Jenkins executes, such as building code, running tests or deploying an application.

docker volume inspect jenkins-data

What is a Freestyle Job?
A Freestyle Job is a basic Jenkins project used to automate tasks such as executing shell commands, building applications and running scripts.

What is a Jenkins workspace?
A workspace is the directory where Jenkins stores and processes files for a particular job.

What does Finished: SUCCESS mean?
It means the build completed without a command returning a failure status.

What is the difference between Jenkins and Docker?
- Jenkins automates software building, testing and deployment.
- Docker packages and runs applications in containers.
