# 📘 The SysAdmin Playbook & DevOps Knowledge Vault

Welcome to my technical knowledge vault! 🚀

This repository documents my learning journey in **Linux System Administration, DevOps, Cloud Computing, Networking, Middleware, and Automation**.

It serves as a structured reference for technical concepts, practical command examples, hands-on exercises, troubleshooting techniques, and technical interview preparation.

### 🎯 What You'll Find Here

- 🐧 **Linux Administration:** Filesystems, users and groups, permissions, process management, services, logs, cron jobs, and SSH.
- 🌐 **Networking:** IP addressing, DNS, HTTP/HTTPS, TCP/UDP, reverse proxies, load balancing, and SSL/TLS.
- 🔧 **Automation & Scripting:** Bash scripting and routine task automation.
- 📦 **DevOps Tools:** Git, GitHub, Docker, Jenkins, CI/CD, Terraform, and Kubernetes.
- ☁️ **Cloud Computing:** AWS fundamentals and cloud infrastructure.
- ⚙️ **Middleware:** Application servers, web servers, configuration, deployment, and troubleshooting.
- 🛠️ **Troubleshooting:** Practical scenarios, diagnostic commands, and resolution steps.
- 💼 **Interview Preparation:** Technical questions, concept revision, and scenario-based questions.

### 📚 My Learning Method

**Learn → Practice → Document → Review → Improve**

Each topic is added progressively as I study and practise it. The goal is to build strong fundamentals, improve practical problem-solving skills, and prepare for real-world technical challenges.
