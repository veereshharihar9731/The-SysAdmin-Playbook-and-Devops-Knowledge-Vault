What are TCP and UDP?
TCP and UDP are transport-layer protocols. They carry data between applications running on different machines.

TCP: Establishes a connection and provides reliable, ordered delivery of a byte stream.

UDP: Sends individual datagrams without establishing a connection first or guaranteeing delivery and order.

TCP
Connection-oriented
- Acknowledgments
- Retransmissions
- Ordered byte stream
- Flow and congestion control
Examples: HTTPS, SSH, most database connections

UDP
Datagram-oriented
- No connection handshake
- No built-in delivery guarantee
- No built-in ordering guarantee
- Low protocol overhead
Examples: DNS queries, many real-time voice/video applications

1. SYN(Client requests a connection.) -----> Server receives SYN

Client receives reply  <-----  2. SYN-ACK(Server acknowledges and responds.)

3. ACK(Client acknowledges the server.) -------> Connection established

SYN: The client asks to establish a TCP connection and provides an initial sequence number.
SYN-ACK: The server acknowledges the client's request and sends its own synchronization request.
ACK: The client acknowledges the server's response. The connection can now carry application data.
