Nginx
Nginx is a web server. It can also work as a reverse proxy and load balancer.

Nginx Configuration and Reverse Proxy
A reverse proxy is a server that receives client requests and forwards them to another server (backend).




Create the project directory

mkdir "$HOME\docker-lab\nginx-reverse-proxy"
cd "$HOME\docker-lab\nginx-reverse-proxy"

Create a custom Docker network
docker network create reverse-proxy-net

docker network ls

Create the Python backend container

docker run -d `
  --name backend-app `
  --network reverse-proxy-net `
  python:3-alpine `
  python -m http.server 8080 --bind 0.0.0.0

docker ps

docker exec backend-app python -c "import urllib.request; print(urllib.request.urlopen('http://localhost:8080').status)"

Expected:
200

Create the Nginx folder:
mkdir nginx


Create default.conf:
$content = @'
server {
    listen 80;

    location / {
        proxy_pass http://backend-app:8080;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
'@

[System.IO.File]::WriteAllText(
    "$PWD\nginx\default.conf",
    $content,
    [System.Text.UTF8Encoding]::new($false)
)


Check the file:
Get-Content .\nginx\default.conf

docker run -d `
  --name nginx-proxy `
  --network reverse-proxy-net `
  -p 8090:80 `
  -v "${PWD}\nginx\default.conf:/etc/nginx/conf.d/default.conf:ro" `
  nginx:alpine


docker exec nginx-proxy nginx -t

docker ps

Docker restart policies work when the container's main process exits. They do not automatically restart a container just because its application becomes unhealthy.

To check restart policy
docker inspect backend1 --format '{{.HostConfig.RestartPolicy.Name}}'

To update restart policy
docker inspect backend1 --format '{{.HostConfig.RestartPolicy.Name}}'


Docker HEALTHCHECK
A Docker health check monitors whether an application inside a container is responding correctly.

- Container running + application responding → healthy
- Container running + application not responding → unhealthy

New-Item -ItemType Directory -Force .\backend-healthcheck
Set-Location .\backend-healthcheck
notepad Dockerfile

FROM python:3-alpine

RUN apk add --no-cache curl

HEALTHCHECK --interval=10s --timeout=3s --retries=3 --start-period=5s CMD curl -f http://localhost:8080/ || exit 1

CMD ["python", "-m", "http.server", "8080", "--bind", "0.0.0.0"]

docker build -t python-healthcheck:v1 .
