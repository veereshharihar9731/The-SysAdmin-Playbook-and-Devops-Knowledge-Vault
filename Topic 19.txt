Git Configuration

git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"

Step 1 — git init
Step 2 — git status
Step 3 — git add .
Step 4 — git commit
Step 5 — git log --oneline



connect your local repository to GitHub:
git remote add origin https://github.com/YOUR-USERNAME/git-practice.git

Rename your current branch to main:
git branch -M main

Verify the remote:
git remote -v

Push your commits:
git push -u origin main

Command						Purpose
git init					Initialize a local repository
git status					Check file and staging status
git add filename			Stage a specific file
git add .					Stage changes under the current directory
git diff					View unstaged changes
git commit -m "message"		Save a local snapshot
git log --oneline			View commit history
git remote -v				View configured remote repositories
git push -u origin main		Push the branch and set its upstream
